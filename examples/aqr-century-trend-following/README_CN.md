## 详细分析

### 背景与研究对象

本例选择策略与组合作为主视角，因为要研究的是一套由多个相互影响的选择组成的交易流程。信号视角辅助解释，但横截面资产排名回答的是另一个问题。若阅读只停留在方向规则，就遗漏了从信号到组合收益所必需的环节。

对新研究者而言，真正困难的是归因：信息本身贡献多少，仓位、分散、杠杆与实现又贡献多少？下方提出的实验围绕这个问题展开。

### 方法与证据

利用 E1–E3 重建依赖链：可选标的 → 可观察收益 → 信号 → 风险配置 → 执行与成本。每个箭头都需要明确时序。使用月末收盘数据计算出的组合，不能自动假定在全部输入已知后仍能以同一个收盘价成交。

将“原文规定”与“自行实现的选择”分开记录。零信号处理、执行延迟或缺失值规则若无法从原文及附录还原，应当记为缺口，不能悄悄补齐后声称完成精确复现。

### 发现与解释

E4 属于原文报告的结果，本例没有重新计算。可以作出的推断是有限的：宽历史覆盖能够挑战只在狭窄样本中有效的解释，但不能消除全部模型选择不确定性。向历史延伸与真正未知的向前检验，提供的是不同种类的证据。

E5 应引出一个时序问题：投资者是否能在这些窗口结束前识别它们？事后压力描述可以刻画策略特征，但不能直接变成实时危机入场规则。后续检验应独立于策略结果定义压力样本，并保留失败与成功两类情况。

### 价值机制与局限——分析者解读

**预测假设：** 若价格调整具有持续性，过去方向可能携带信息。但历史关联本身不能识别成因，竞争解释需要另行检验。

**组合假设：** 分散信号周期或许能降低对单一回看期的依赖。这是本例提出的扩展，不代表原文已经证明多周期组合优于风险匹配的单周期基准。

**风险管理含义：** 动态变化的策略暴露可能补充传统配置。但评价时需要匹配风险预算，并考察恢复速度、尾部表现和实现条件。具有配置价值，也可能无法保护每一次突然反转。

由此产生三个实际限制。第一，历史时点可用的标的集合，容易被今天的幸存者名单替代。第二，需要区分代理收益与当时实际可交易的合约，E6 尤其提示了这一点。第三，E3 中未计入或不确定的成本，意味着应做敏感性分析，而非给出一个过度确定的净收益判断。

### 复现与后续工作

先选择一个现代且资料充分的标的集合，确保能够审计逐合约数据、换月、时间戳和融资口径。保存数据清单与代码版本。先还原基准，再尝试改进；匹配风险与杠杆，同时报告换手和成本。偏离原文的实现应明确标注。

### 假设与机制

- **Alpha 类型：** 预测 / 组合构建。
- **可检验主张：** 在指定的现代期货标的集合中，按原文思路构建的多周期组合，在相同事前风险预算下，相对固定 12 个月方向基准提高扣成本后 Sharpe。
- **价值机制：** 平均多个周期可能降低选错时间尺度的影响，尚未验证。
- **替代解释：** 差异可能来自杠杆、换手、暴露或成本假设，而非信息增量。
- **失效条件：** 震荡反转、额外交易成本、信号冗余，或改善仅出现在特定挑选的样本。

### 数据与实现

- **样本与时期：** 尚未选定。计算结果前冻结历史入选资格与样本边界，不按事后赢家挑标的。
- **输入及可获得时间：** 需要合约价格、换月、乘数、融资和可执行成本估计；供应商及时点规则待数据选定后明确。

### 拟议验证方案——尚未执行

- **基准与消融：** 固定 12 个月基准、多周期组合，以及作为诊断的短周期版本；匹配风险预算与约束，不在留出样本中事后挑最优基准。
- **样本切分：** 按时间顺序安排开发段与外部检验段。已看过的时期不能称为真正未知；记录既有接触情况，必要时补充前瞻证据。
- **主要指标与规则：** 相对基准的净 Sharpe 差。拟议研究判定为：差值为正且考虑序列依赖的 95% bootstrap 区间下界高于零，才支持改善；上界不高于零则拒绝正增量主张；其余标为无法判定。运行前冻结重采样设计。
- **稳健性：** 比较成本压力、市场子集、周期消融、实际风险、换手和杠杆；记录全部尝试，区分次要诊断与主检验。
