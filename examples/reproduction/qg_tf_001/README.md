# QG-TF-001 — synthetic reproduction pipeline

**Level: pipeline_demo. Conclusion: untested_synthetic.**

This is a runnable, independently written research-accounting example motivated by the
[AQR source and evidence record](../../aqr-century-trend-following/SOURCE.md).
It does not reproduce the paper's historical data or performance.

- [Experiment specification](experiment.yaml): fixed candidate horizons, 12-month baseline, costs and evaluation.
- [Data manifest](data_manifest.json): fingerprint, fictional universe, timestamps and MIT use/redistribution declaration.
- [Original synthetic CSV](synthetic.csv): 180 months, four fictional instruments. No observed financial returns.
- [Saved run](sample-run/report.md): generated by the actual reference runner.
- [Full installation/data/CLI guide](../../../docs/reproduction.md).
- [Rights and dependency notes](../../../THIRD_PARTY_NOTICES.md).

The hypothetical ensemble is compared with a fixed 12-month baseline and 1-/3-month diagnostics.
All parameters and costs are illustrative. Metrics measure this synthetic scenario only.
Do not tune the fixture to obtain an attractive result or market it as investable alpha.
Regenerate inputs with `python scripts/make-synthetic-fixture.py`; fresh execution creates a new run ID.

Historical data may be supplied locally with explicit provenance and rights. Keep restricted data outside tracked directories.
Version 0.3 also provides [cross-sectional and model experiments](../../../docs/panel-experiments.md); infra execution remains planned.
