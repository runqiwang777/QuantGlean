## Installed dependencies

Dependencies retain their own licenses; QuantGlean's MIT license does not relicense them.
Install distributions from their official package sources and retain their bundled licenses when redistributing an environment.

| Component | Declared use | License / official source |
| --- | --- | --- |
| NumPy | Array calculations | [BSD-3-Clause](https://github.com/numpy/numpy/blob/main/LICENSE.txt) |
| pandas | Local series/data frames | [BSD-3-Clause](https://github.com/pandas-dev/pandas/blob/main/LICENSE) |
| PyYAML | Safe YAML parsing; no object construction | [MIT](https://github.com/yaml/pyyaml/blob/main/LICENSE) |
| PyArrow (optional) | Local Parquet I/O | [Apache-2.0](https://github.com/apache/arrow/blob/main/LICENSE.txt), with distribution notices |
| QuantStats 0.0.81 (optional) | Public reports.html API with local return Series | [Apache-2.0](https://github.com/ranaroussi/quantstats/blob/main/LICENSE.txt) |
| pytest (development) | Automated checks | [MIT](https://github.com/pytest-dev/pytest/blob/main/LICENSE) |

QuantStats and its transitive dependencies are installed separately, not vendored.
Its generated report is supplementary. Preserve any generated notices and disclose the pipeline_demo level.
No ticker lookup, Yahoo download, or external financial dataset is used by QuantGlean's adapter.
The exact installed versions are recorded in each run; dependency resolution should be rechecked when upgrading.

## Research sources and data

The AQR paper is attributed by title, authors, URL, evidence IDs and inspected-version SHA256 in
[the source record](examples/aqr-century-trend-following/SOURCE.md).
We publish our own analysis and implementation choices, not the paper PDF, figures, or original historical dataset.
A public download link is not a grant of redistribution rights.

The example CSV is entirely generated by our original deterministic generator, uses fictional symbols,
and contains no observed market returns. It is released with this repository under MIT.
Its metrics have no investment meaning and are not a replication of AQR's reported results.

For user-supplied datasets, record the source terms, permitted research use, redistribution permission and provenance.
A checkbox or manifest declaration does not grant rights that the user does not possess.
Do not commit restricted input data, confidential research, personal information, credentials,
or restricted derived outputs. local-work is excluded locally; the repository also ignores common run/cache directories.
Do not publish a run merely because it completed.
